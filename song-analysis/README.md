# Разбор песен нейросетью

Для семи встроенных дней открытая нейросеть Demucs разделила 30-секундные официальные отрывки песен на дорожки.

- `hits.py` — удары бочки и малого барабана из дорожки барабанов.
- `vox.py` — акценты голоса из дорожки вокала.

В проект попадают только числа (время и сила акцентов) — они записаны в `demo/days-kino.json`. Сами песни и дорожки не хранятся.
