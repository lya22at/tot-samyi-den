# Тот самый день

Личный дневник, в котором каждый день — разворот тетради и маленький фильм.
Проект для хакатона ArtTech «Make the Invisible Visible».

**Открыть:** https://lya22at.github.io/tot-samyi-den/

## Как это работает

Нужны три вещи: рассказ о дне (можно написать, можно надиктовать голосом), фото (или короткие видео) и песня (достаточно названия и исполнителя).

- **Песня решает, как выглядит день.** Сайт слушает файл, находит темп и энергию и по ним выбирает цвет бумаги разворота, наклон фотографий, «пляску» букв-вырезок, длину кадров и резкость склеек в фильме.
- **Текст** даёт название папки дня, подписи-субтитры в фильме и рисунки на полях (волны, солнце, капли, лист, луна, чашка).
- **Фото и видео** становятся полароидами на развороте и кадрами фильма дня.
- **Год** — календарь, где каждый записанный день лежит клочком своей бумаги; нажатие открывает день.
- **Фильм дня** можно сохранить как видео.

Всё работает прямо в браузере: файлы никуда не отправляются, свои дни хранятся на устройстве.

## Типы дней

Бумага показывает, как день **звучал** (её выбирает песня). Тип показывает, как день **ощущался** — его выбирает сам человек, сайт только предлагает по словам: «Всё по маслу», «Как дома», «Водоворот», «На паузе», «Не мой день», «Терпение на нуле». Названия придумала команда.

- **Что было потом** — у трудного дня видно ближайший светлый: «Через 3 дня был день „Как дома“».
- **Дни как этот** — под разворотом лежат другие дни того же типа.
- **Год** — можно оставить в календаре только один тип.
- **Мне непросто** — тёплые дни и их песни, свои же строчки «что получилось», вопрос «что бы ты сказала подруге?». Трудные дни показываются только по просьбе и вместе с тем, чем они закончились.

Мы заметили, что дни повторяются. Когда плохо, полезно увидеть, что такой день уже был и закончился. Дневник не лечит и не советует — он показывает. Идея перекликается с практикой дневника настроения; подсчётов «плохих» дней, серий и выводов о состоянии в нём нет намеренно.

## Файлы

- `index.html` — весь сайт «Тот самый день» (разметка, стили, код)
- `demo/days-kino.json`, `demo/real/`, `demo/*.mp3` — демо-дни
- `mood/` — 36 «кадров настроения»: если своих фото мало, фильм добирает кадры по словам из текста
- `tex/` — бумага, стол и предметы коллажа (скотч, скрепка, лист, записка, марка, билет, чек)
- `kartiny.html`, `app.js` — первая версия проекта («Картины дней»), оставлена для истории

## Инструменты

HTML, CSS, JavaScript; для передачи фото с телефона по QR — библиотека qrcode-generator и сервис пересылки ntfy (открытая программа, развёрнута на своём сервере) (фото шифруются на телефоне); Web Audio API (анализ песни), Canvas и MediaRecorder (фильм и запись видео), IndexedDB (хранение дней), шрифты Google Fonts.
Web Speech API (диктовка голосом), открытый каталог iTunes Search (поиск песни и её 30-секундный отрывок).
Демо-фотографии, кадры настроения, текстуры бумаги и предметы коллажа сгенерированы нейросетью (Higgsfield), демо-мелодии — тестовые. Код написан с помощью Claude.
