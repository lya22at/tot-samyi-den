# Telegram-бот «Тот самый день»

Ещё один способ записать день: человек пишет боту о дне, присылает фото и называет песню.
Бот отправляет запись и кадры нейросети Claude, та возвращает главные слова дня и раскадровку фильма.
Потом бот шифрует день и даёт ссылку, по которой сайт открывается с уже заполненным днём.

- `bot.mjs` — разговор в Telegram, шифрование и передача дня сайту.
- `nn.mjs` — вызов Claude (официальная библиотека Anthropic).
- Ключи в репозитории не хранятся: `token.txt` (Telegram) и `claude-key.txt` (Claude) лежат только на сервере.

Запуск: `docker compose up -d` в папке, где рядом лежат оба файла с ключами.
